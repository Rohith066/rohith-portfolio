# Rohith Bayya: portfolio

Static site (HTML, CSS, vanilla JS). No build step.

## Run locally

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765

## Deploy on GitHub Pages

Push this folder to a repo, then in the repo go to Settings, Pages, and set the source to the `main` branch, root folder.

## Notes

- `assets/Rohith_Bayya_Resume.pdf` is a copy of the master resume with the phone number removed.
- `.build/` holds the intermediate .docx and is gitignored. Do not commit it.
- Track views can be linked directly: `#de`, `#da`, `#ai`.
